┌──────────────────────────────────────────────────────────────┐
│ STEP 1: IMPORT DATABASE (5 menit)                            │
└──────────────────────────────────────────────────────────────┘

1. Start Laragon → Klik "Start All"
2. Buka: http://localhost/phpmyadmin
3. Klik "New" → Database name: toko_api → Create
4. Pilih database "toko_api"
5. Tab "Import" → Browse → Pilih file:
   C:\laragon\www\toko_api\database.sql
6. Scroll ke bawah → Klik "Go"
7. ✅ Selesai!

❌ CONNECTION REFUSED?
→ Test di browser: http://localhost/toko_api/
→ Pastikan Laragon running (Apache & MySQL hijau)
→ Untuk Android emulator, URL: http://10.0.2.2/toko_api

❌ DATABASE ERROR?
→ Cek di phpMyAdmin: database toko_api ada?
→ Tabel users & produk ada?
→ Kalau belum, import ulang database.sql

❌ FLUTTER ERROR?
→ flutter clean
→ flutter pub get
→ flutter run
